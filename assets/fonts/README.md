# Vendored Fonts

These unmodified variable-font binaries were obtained from the official
Google Fonts repository at commit
`5e35378e6bda803962ee6fd257e444a7d459660d`. They are served from the module's
same-origin asset route so the UI does not require external style or font CSP
exceptions.
